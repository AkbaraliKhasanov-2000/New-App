Scanmuse는 iPhone을 빠르고 안전한 PDF 스캐너로 바꿔 줍니다. 문서, 영수증, 신분증, 계약서, 손글씨 메모를 스캔하고, 기기 내 OCR로 텍스트를 인식해 검색 가능한 깔끔한 PDF를 몇 초 만에 공유하세요.

전문가 수준의 스캔
• 문서 가장자리 자동 감지, 원근 보정, 여러 페이지 연속 촬영
• 자동, 선명, 회색조, 흑백 필터로 그림자를 없애고 글자를 또렷하게
• 사진과 파일에서 이미지·PDF 가져오기 — 사진 속 문서는 자동으로 자르기
• 네 모서리 수동 자르기, 회전, 페이지 순서 변경 및 삭제

사진 텍스트 추출(OCR)
• 인쇄된 텍스트를 여러 언어로 iPhone에서 바로 인식
• 인식한 텍스트 복사, 공유, 번역
• 보관함에서 모든 스캔 내용 검색
• 어떤 PDF 앱에서도 선택·검색할 수 있는 PDF 만들기

서명과 보호
• 서명을 한 번 그려 두고 어느 페이지에나 배치
• 공유 전에 PDF에 암호 설정
• Face ID로 앱 전체 잠금

정리와 공유
• 폴더, 즐겨찾기, 정렬, 격자/목록 보기
• 여러 스캔을 하나의 문서로 병합
• PDF, JPG, 텍스트로 내보내기. A4, US Letter, 이미지에 맞춤 용지 선택
• 메일, 메시지, AirDrop, 파일에 저장, 프린트

개인정보 보호 중심
Scanmuse는 계정도 클라우드도 필요 없습니다. 문서와 인식된 텍스트는 기기에만 저장됩니다.

Siri 및 단축어와 함께 사용할 수 있습니다.
